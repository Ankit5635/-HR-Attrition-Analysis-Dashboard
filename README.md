# 📖 Project Overview

The **HR Attrition Analysis Dashboard** is an interactive web-based analytics dashboard developed using **HTML, CSS, JavaScript, and Chart.js**. It provides valuable insights into employee attrition, workforce demographics, departmental performance, and retention trends.

The dashboard is designed to help HR professionals and business managers understand employee turnover patterns, identify high-risk departments, and support data-driven decision-making.

---

# 🎯 Project Objectives

* 📈 Analyze employee attrition trends
* 👥 Monitor workforce demographics
* 🏢 Compare department-wise performance
* 📊 Identify key attrition factors
* 💡 Support strategic HR decisions

# 📊 Dashboard Pages

## 📌 1. Attrition-Wise Analysis

Displays overall employee statistics including:

* Total Employees
* Attrition Count
* Attrition Rate
* Average Tenure

Charts Included:

* Department-wise Attrition
* Age Group Analysis
* Gender Distribution
* Job Role Analysis
* Salary vs Attrition Trend

---

## 👋 2. Employee Left Company

Provides detailed analysis of employees who resigned.

Includes:

* Employees Left KPI
* Average Age
* Average Salary
* Average Tenure

Visualizations:

* Department-wise Attrition
* Education Field Analysis
* Marital Status Distribution
* Job Level Funnel Chart

---

## ✅ 3. Employee Stayed Company

Analyzes retained employees.

Displays:

* Total Retained Employees
* Average Age
* Average Salary
* Average Tenure

Visualizations:

* Department-wise Retention
* Job Satisfaction
* Gender Distribution
* Business Travel Analysis
